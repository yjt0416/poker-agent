# 2026-09-22 Agent 记忆与情绪验收

本轮完成同场锦标赛内的记忆闭环，尚不代表完整游戏或发布验收完成。

## 已实现

- 每个 AI 座位独立记录对手的公开行动、加注/全下、弃牌和发言次数；统计不包含对手底牌，也不冒充可验证的诈唬率。
- `memoryUpdates` 保存为最多 12 条、每条 240 字符的私有笔记，只有对应 Agent 的后续决策可读。保存最近 6 条发言，拒绝近期完全重复台词；离线模式提供替代句。
- 记忆与牌局状态、回放帧一起提交，归档失败一并回滚。PostgreSQL 保存 JSONB，重启后继续使用；旧会话没有记忆字段时从空记忆恢复。
- 胜负影响情绪，下一手逐步衰减；离线台词可回应上一手胜负。前端显示沉着、警觉、紧张等公开状态，不暴露私有笔记。
- 离线策略移除聊天文本哈希对行动的大幅扰动，公开统计偏移限制在 ±5，聊天次数偏移最多 3。DeepSeek 接收带不可信标记的笔记与近期发言；所有尖括号转义，非法动作仍执行校验、一次修复及本地降级。

## 验证

- Java 21：317 项常规测试通过；真实 PostgreSQL 17.11：12 项 LocalIT 通过。对应 12 项 Docker 测试因无 daemon 跳过。
- 持久化用例实际写入私有笔记、关闭并重建应用上下文，再验证后续决策读取记忆且回放不泄露笔记。
- 13 项前端测试与生产构建通过；5 项 Chromium E2E 在 PostgreSQL 后端下通过。
- 内置浏览器实测：单步后情绪从“沉着”变为“警觉”；自动观战进入冠军与排名页，刷新恢复终局，进入脱敏回放。
- DeepSeek 使用本地模拟 HTTP 服务验证提示词封装及非法动作降级，没有使用真实密钥调用。

## 尚缺与边界

当前记忆只属于一场锦标赛，会话仍为 8 小时；另开一桌不会继承旧桌画像。local 模式进程退出仍丢失状态。跨桌身份、历史恩怨、关系网络、挑衅语义识别和可靠诈唬统计尚未实现。

近期完全重复过滤不是语义去重，替代句耗尽时允许沉默。数值影响上限仅适用于离线决策器；提示词封装不意味着对 LLM 策略变化有数学上限或绝对防注入保证。当前情绪是文字状态，没有角色动画或声音。

浏览器观战也出现过一手多方全下即结束锦标赛的局面。引擎允许该合法结果，但离线策略的下注尺度和筹码风险偏好值得后续调优，以改善对局长度与可玩性。
