# 2026-09-23 牌桌声音与动态反馈

已加入右上角“声效”面板，提供启用/静音、0–100 音量及减少动态效果。音量和动态偏好保存在本机；每次打开页面仍默认静音，点击后才创建和恢复 Web Audio 上下文。无音频 API 时显示错误，不影响牌局。

根据连续、已提交的牌桌状态区分发牌、下注、弃牌、过牌、全下与结算，播放短合成提示音。首次恢复、重复帧、跨桌与跳号状态保持安静；快速连续补帧合并声音，后台页面不播放。聊天不会重复触发上一条行动的声音。回放和大厅不播放后台牌桌行动。

当前动态反馈包括公共牌出现、底池/下注强调、弃牌标识和结算强调。动画短于 4× 观战步进间隔，不延迟或改变权威牌局。应用内减少动态效果和系统 `prefers-reduced-motion` 任一开启都会禁用动态反馈。

## 尚缺

目前是轻量合成音及视觉强调，尚无环境音乐、真实筹码/翻牌录音、筹码移动路径、完整摊牌与分池动画、角色骨骼/表情动画或回放音效。这些不能标记为完整音画验收。发布工程、战绩成长和跨桌记忆等范围仍见 README。
