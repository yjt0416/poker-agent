# 2026-09-22 离线策略与对局节奏

## 原因与修改

此前离线策略没有使用底牌，也不判断跟注占剩余筹码的比例。相同玩家在同一公共牌面上反复触发相同加注分支，遇到高耐心角色的大额跟注，容易很快推到多人全下。

现使用起手牌评分及引擎已有的公开牌型计算。只读取自身底牌与公共牌，不获取其他玩家底牌；通过显式的 `game::handvalue` 模块接口复用计算，架构检查保持启用。河牌完全使用公共牌构成牌型时，避免把共享强牌当作自身独有优势。

根据牌力设置整手投入预算（包含此前各街已投入筹码），同时判断跟注价格。加注目标区分本街已下注额与整手投入额，并限制在合法范围和剩余预算内。强成牌仍可跟注至全下；免费过牌不受已耗尽预算阻止。角色激进度、诈唬倾向、耐心和受限的记忆/聊天影响仍参与决策。

## 验收

- 324 项后端测试通过，包括新增 6 项策略测试及 1 项连续多手服务测试。
- 覆盖全部角色面对弱牌大额跟注、强起手牌正常继续、整手预算耗尽、免费过牌、共享公共牌强牌、私有葫芦跟注全下，以及加注金额合法性。
- 连续多手服务测试检查行动合法、每手结算后总筹码 60,000、首手保留至少 3 人，且能继续后续手牌。
- Windows 预览进程占用 JAR 导致首次打包失败；停止旧预览进程后，已成功重新打包并以 PostgreSQL 配置启动新版。
- 新版后端下 5 项 Chromium E2E 全部通过。内置浏览器恢复原观战桌后，以 4× 连续播放至第 16 手，六个座位仍有筹码，跨手情绪与胜负回应正常；验收后已暂停。

## 边界

这是保守启发式，不是胜率计算或最优扑克策略；目前没有完整听牌赔率、对手范围估计或博弈求解。共享强公共牌的处理可能过于保守。投入限制会减少早期大额对抗，但不保证每场比赛长度，也不禁止合理全下。

真实 DeepSeek 的决策逻辑未替换；它仍使用原有的过牌/弃牌安全降级，本次改动针对无密钥离线模式。全局发布、动画音效和跨桌关系等未完成事项仍见 README。
