# 2026-09-23 匿名本地战绩验收

本轮完成战绩与成长中的本地统计基础。大厅增加“本地战绩”入口，结果页显示累计摘要并可进入战绩页。

## 已实现

- 只统计玩家模式：完赛局数、夺冠次数/胜率、累计游戏积分盈亏、已结算手数和最大底池。
- 按自身已确认行动统计弃牌、过牌、跟注、加注和全下，展示最常用动作。
- 完赛后按所选角色记录交手局数和玩家击败该角色的次数。
- 使用每桌事件序号游标去重；刷新、SSE 重连、重复帧及 React 严格模式不会重复累计。观战桌完全忽略。
- 数据仅保存在当前浏览器 `localStorage`，不进入 Web 会话、PostgreSQL、SSE 或回放。页面明确说明清站点数据和更换浏览器会丢失记录。
- 清除战绩采用页面内两步确认；不会删除牌局会话或服务端数据。

## 验证

- 前端 22 项测试和生产构建通过。新增测试覆盖行动/结算去重、最大底池、完赛盈亏、角色交手、观战忽略、损坏存储降级、页面展示和清除确认。
- 7 项 Chromium E2E 全部通过。新增用例覆盖预置本地战绩、刷新恢复、两步清除及清除后的再次刷新。
- 内置浏览器检查大厅入口、空战绩状态、隐私说明和桌面布局；页面保持在战绩页供继续查看。
- 本轮未改服务端，未重复运行上一轮已通过的 324 项后端测试与 12 项 PostgreSQL 契约。

## 边界

累计盈亏以每局固定初始 10,000 筹码为基线，规则自定义落地时必须改为由规则快照提供。多标签页同时写入不同牌桌的极端竞态仍可能发生最后写入覆盖；当前匿名会话一次只保留一桌，正常使用路径不受影响。

目前不保存可重新打开的历史牌局，不含云同步、精彩手牌收藏、成就、等级、难度或不同茶馆主题。角色交手是结果统计，不等同于 Agent 的跨桌记忆与关系网络。
