# Agent Tavern Agent、实时 API 与可玩牌桌实施计划

**目标：** 在已完成的六人锦标赛与 PostgreSQL 恢复能力之上，交付一个无需真实 LLM Key 也能运行、配置 DeepSeek 后可切换为 LLM Agent 的浏览器游戏垂直切片。

**原则：** 服务器始终权威；原始检查点和事件不出服务端；每个客户端只接收其受众投影；LLM 只能在合法动作集合中选择，失败时确定性降级；先保证完整可玩，再逐步提高美术与玩法深度。

## 里程碑 A：Agent 与聊天基础

1. 新增 `agents` 模块、八名角色、情绪与有限私有记忆模型。
2. 定义只含单个 Agent 可见信息的 `AgentObservation`，用架构测试阻止基础设施反向渗透。
3. 定义 `AgentDecisionProvider` 端口与结构化决策校验器；非法动作、空响应、异常和超时降级为 CHECK/FOLD。
4. 提供确定性本地 Provider，保证无 Key 的开发、CI 和演示可完成整局比赛。
5. 新增 DeepSeek OpenAI-compatible Provider，密钥只读环境变量；正常与一次修复调用均有预算、超时和脱敏日志测试。
6. 新增 `table-chat` 模块，完成 240 字符、5 秒冷却、控制字符拒绝、纯文本语义和不可信输入分隔。

## 里程碑 B：实时后端与基础可玩前端

1. 新增匿名 HttpOnly 会话、玩家模式创建/查询/行动/聊天 REST API。
2. 新增严格脱敏的玩家/观众投影；任何测试不得在非导演视角发现对手底牌。
3. 新增提交后 WebSocket/SSE 事件流、断线后按最后序号补发。
4. 新增 React 19 + TypeScript + Vite 前端：大厅、选角、六人牌桌、下注、聊天、结果页。
5. 加入自动 Agent 回合调度，使玩家只需在自己回合操作。
6. 提供开发脚本和 Docker Compose；README 给出从零启动步骤。

## 里程碑 C：品质、观战与发布

1. 依照已批准视觉稿实现木纹、丝绒、黄铜、暖光牌桌和响应式布局。
2. 加入八名 Q 版角色资产与待机/思考/得意/紧张状态、发牌/筹码/胜者动画、音效与减少动态效果。
3. 实现 AI 对战的暂停、单步、倍速、Agent/导演视角。
4. 实现逐动作回放、关键手牌、匿名战绩和 Token/延迟统计。
5. 完成 Vitest、Playwright、截图、无障碍、Docker、CI、安全与一键启动验收。

## 当前执行顺序

按 A1→A6、B1→B6、C1→C5 连续实施。每个小步必须包含测试、独立提交和全量验证；默认路径永远不依赖真实 DeepSeek 网络调用。
